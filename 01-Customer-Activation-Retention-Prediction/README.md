# Customer Activation & Retention Prediction

Portfolio-safe machine learning project for predicting customer activation, retention, and churn risk.

## Objective

Predict customer activation, retention, and churn risk using customer behavioral and transaction features.

## Workflow

Data ingestion → data cleaning → feature engineering → customer behavior aggregation → model training → probability scoring → retention prioritization.

## Models

- Logistic Regression
- Random Forest
- Gradient Boosting
- XGBoost

## Evaluation

- Precision
- Recall
- F1-score
- ROC-AUC
- Probability calibration

## Technologies

Python, Pandas, NumPy, Scikit-learn, XGBoost, SQL, MLflow.

## Production Considerations

Batch scoring, model versioning, drift monitoring, threshold tuning and rollback-ready deployment.

## Data Privacy

This portfolio project uses public or synthetic data. No proprietary client, TCS or confidential business data is included.
